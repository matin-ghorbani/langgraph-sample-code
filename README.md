# langgraph-sample-code

This sample code is a minimal intent-based multi-agent router built with LangGraph, demonstrating state management, structured LLM classification, and conditional branching between two persona-specific agents.

## How to run

Create a `.env` file with these values:

- `API_KEY`: Your LLM provider API key
- `BASE_URL`: Your LLM provider base url

Install requirements:

```bash
pip install requirements.txt
```

run: `python3 main.py`
